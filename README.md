# Bantek Interior - Luxury Architecture & Interior Design

A modern, ultra-responsive, and premium multi-page website built for **Bantek Interior**, a high-end interior architecture and design firm.

![Bantek Interior](https://images.unsplash.com/photo-1600210492486-724fe5c67fb0?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **Luxury Aesthetics & Typography**: Curated typography (Cinzel & Plus Jakarta Sans) with warm amber and champagne gold accents.
- **Dynamic Dark & Light Mode**: Persistent theme switching with real-time CSS variable transitions.
- **Interactive Cost Estimator**: Comprehensive multi-step room and finish calculator with instant quote estimations.
- **AI Concierge Chatbot**: Intelligent virtual assistant ready to answer design queries, budget estimations, and appointment bookings.
- **Fully Responsive Architecture**: Custom-engineered mobile navigation drawer, fluid typography, touch sliders, and optimized mobile headings.
- **Interactive Portfolio Gallery**: Filterable project showcases (Living, Kitchen, Bedroom, Commercial) with high-definition lightbox viewer.
- **Quick Connect Actions**: Sticky WhatsApp and direct call triggers for rapid client onboarding.
- **Google Maps & Contact Integration**: Interactive contact and consultation booking form with embedded studio map.
- **Micro-Animations & Smooth Physics**: Custom trailing luxury cursor, magnetic buttons, parallax hero, and scroll reveal animations.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 8080

# Using Node.js (npx)
npx serve .
```

Visit `http://localhost:8080` to experience the website.

- **HTML5**: Semantic markup, accessible forms, and modern web standards.
